$jarakMeter = 6371000 * (2 * atan2(sqrt($a), sqrt(1 - $a)));

Karakteristik Kode: Rapi, Terukur, & Terbaca

Setiap baris kode ditulis dengan mempertimbangkan rekan pengembang berikutnya yang akan membaca repositori. Penamaan variabel yang representatif, validasi kondisi batas sebelum mengeksekusi logika utama, dan penanganan kegagalan secara terencana.

PHP 8.2 
<?php

namespace App\Services;

final class GeofenceVerificationService
{
    // Radius maksimum kehadiran yang diizinkan (dalam satuan meter)
    private const MAX_ALLOWED_DISTANCE_METERS = 50.0;

    public function verifyCoordinates(
        float $employeeLat,
        float $employeeLon,
        float $officeLat,
        float $officeLon
    ): bool {
        $distance = $this->calculateHaversine(
            $employeeLat, $employeeLon, 
            $officeLat, $officeLon
        );

        return $distance <= self::MAX_ALLOWED_DISTANCE_METERS;
    }
}
