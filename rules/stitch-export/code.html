Sistem Absensi Karyawan Berbasis Geofencing

Mencegah kecurangan presisi kehadiran mobile pada lokasi kantor terdistribusi. Dibangun menggunakan Laravel 10 dengan Livewire 3 dan Alpine.js, sistem secara kontinyu memvalidasi letak geografis karyawan menggunakan formula lingkaran bola Haversine dengan interval sinkronisasi 15 detik tanpa membebani browser.

LOGIKA HAVERSINE (PHP NATIVE / SERVICE CLASS) RADIUS VALIDASI: 50 METER
$dLat = deg2rad($latEmp - $latOffice);
$dLon = deg2rad($lonEmp - $lonOffice);
$a = sin($dLat/2)**2 + cos(deg2rad($latOffice)) * cos(deg2rad($latEmp)) * sin($dLon/2)**2;
$jarakMeter = 6371000 * (2 * atan2(sqrt($a), sqrt(1 - $a)));

Anonymous Real-Time Chat Platform

Platform obrolan instan tanpa keharusan membuat identitas permanen, meminimalkan jejak digital pribadi pengguna. Dibangun dengan basis PHP murni (Native) untuk membuktikan pemahaman mendalam atas manipulasi HTTP state, dipadukan dengan Firebase Realtime Database sebagai engine sinkronisasi pesan paralel antar-klien.

• Sanitasi XSS Berlapis: Seluruh muatan teks disanitasi menggunakan fungsi kustom sebelum masuk ke simpul Firebase, mencegah injeksi skrip HTML jahat.
• Sesi Ephemeral: Identitas ruang obrolan dibuat menggunakan token acak terenkripsi yang kadaluwarsa saat tab browser ditutup.
• Ringan Dependensi: Tidak bergantung pada runtime Node.js server besar, cukup server PHP terpasang umum.
Backend: PHP Native (No Framework)

app/Services/GeofenceVerificationService.php
PHP 8.2 
<?php

namespace App\Services;

final class GeofenceVerificationService
{
    // Radius maksimum kehadiran yang diizinkan (dalam satuan meter)
    private const MAX_ALLOWED_DISTANCE_METERS = 50.0;

    public function verifyCoordinates(
        float $employeeLat,
        float $employeeLon,
        float $officeLat,
        float $officeLon
    ): bool {
        $distance = $this->calculateHaversine(
            $employeeLat, $employeeLon, 
            $officeLat, $officeLon
        );

        return $distance <= self::MAX_ALLOWED_DISTANCE_METERS;
    }
}
